# Финансовые шортсы с телефона

## Один раз настроить
1. Открой приложение Claude → вкладка **Code** (или сайт claude.ai/code) и подключи GitHub, когда предложит.
2. Выбери этот репозиторий. В настройках окружения (Environment) включи доступ к интернету (Network access: Full).
3. Если хочешь голос ElevenLabs, добавь там же переменную `ELEVENLABS_API_KEY` со своим ключом. Без ключа будет бесплатный голос.

## Сделать ролик
Напиши Claude, например: «Сделай шортс про то, как зарабатывает Тесла». Он сам напишет текст, озвучит, соберёт и отрендерит ролик.

Готовое видео появится в папке `videos`: открой файл на github.com → «⋯» → **Download**.
