# Код эталонных сцен (только для чтения)

Это настоящие сцены из эпизода «Ложь» (Lie_v5). Они написаны под проект эпизода: импорты (`./core`, `./cast`, `L('085')`, персонажи `leva`/`gosha`) там другие, поэтому не копируй файлы целиком — бери приёмы.

| Файл | Что посмотреть |
|---|---|
| `opening.tsx` | Холодное начало из 4 планов в одной сцене (`own`): паспорт с «16» и штампом → вход к зеркалу (walkTo, размытие) → касания лица с выносками (gesture/reach, armOver, Callout) → неоновая табличка 16→34 → сплит. Резы — по словам реплики |
| `gosha.tsx` | Встреча во дворе: вход с двух краёв, рукопожатие (reach через toLocal), жесты на каждое слово («космонавт» — палец вверх, «подтянулся» — подтягивания, «рэпер» — палец у губ), пузыри живут только на своём слове. Коридор: друг подходит и трогает щетину пальцем (IK к чужой точке), проверки с жестами |
| `shotsA.tsx`, `shotsB.tsx` | Все 57 остальных сцен эпизода: кухня с диалогом (камера по говорящему), лифт с зеркалом, чат в телефоне, доски правил, инфографика, дискотека, пожар и паника толпы, схема эвакуации, ночная кухня с рукой через стол |
| `Episode.tsx` | Сборка лонга: список сцен, авторакурсы, вжухи |
| `Short.tsx` | Шортс-перемонтаж из лонга: сегменты на реплики, кроп, вертикальные карточки, сплит сверху/снизу |
