# Озвучка

Реплики лежат в `src/story/lines.json`: `{"id": "007_HERO", "sp": "HERO", "t": "текст", "action": "...", "graphic": "..."}`. Id — трёхзначный номер и код говорящего. `N` — рассказчик, остальные — id персонажей в верхнем регистре. Готовые файлы кладутся в `public/vo/`.

Перед началом скажи пользователю, сколько знаков озвучиваем (`node -e` посчитать сумму длин `t`) и, для ElevenLabs, сколько это кредитов.

## Вариант 1. Бесплатно, без регистрации (по умолчанию)
Нейроголоса Microsoft Edge. Работают без аккаунта, нужен только интернет.
1. Заполни `src/story/voices.json`: `{"N": {"voice": "ru-RU-DmitryNeural", "rate": "+6%"}, "HERO": {"voice": "en-US-AndrewMultilingualNeural", "rate": "+8%"}}`.
2. `node tools/voice-free.mjs` → `public/vo/<id>.mp3`. Повторный запуск пропускает готовые файлы. `--force` — переозвучить все, `--only 007,012` — только эти.

Голоса:
- **Русские:** `ru-RU-DmitryNeural` (муж., хороший рассказчик), `ru-RU-SvetlanaNeural` (жен.).
- **Многоязычные** (говорят по-русски с лёгким акцентом, годятся для персонажей): `en-US-AndrewMultilingualNeural`, `en-US-BrianMultilingualNeural` (мужские), `en-US-AvaMultilingualNeural`, `en-US-EmmaMultilingualNeural` (женские).
- **Английский** (если ролик на английском): `en-US-GuyNeural`, `en-US-ChristopherNeural`, `en-US-EricNeural`, `en-US-RogerNeural` — документальные.

Темп: рассказчик +5…+10 %, персонажи −5…+12 % по характеру. `pitch` ±2–4 Hz разводит похожие голоса. Теги в квадратных скобках (`[excited]`) бесплатный голос не понимает — скрипт их вырезает.

## Вариант 2. ElevenLabs (у пользователя свой аккаунт)
Качество выше, есть эмоции (`[tired]`, `[excited]`, `[whispers]` в начале реплики). Модель — Eleven v3/v4 Turbo: 0,5 кредита за знак, каждая генерация даёт 2 дубля по цене одного.

Порядок (через браузер пользователя, Claude in Chrome):
1. Пользователь сам входит в свой аккаунт ElevenLabs. Пароли не вводить, аккаунт не регистрировать, ничего не покупать. Если вход через Google — пусть нажмёт сам.
2. В проекте запусти приёмник файлов: `node tools/receiver.mjs` (в фоне). Он сохраняет присланные байты в `public/vo/`.
3. На странице Text to Speech выполни JS (javascript_tool):
   - **перехват ответов:** оберни `window.fetch`, клонируй ответы, URL которых содержит `text-to-dialogue` или `text-to-speech` (audio/mpeg), складывай в `window.__caps`;
   - **ввод текста:** `__setText(t)` — выделить содержимое редактора `.ProseMirror` через Range и `document.execCommand('insertText', false, t)`;
   - **генерация:** нажать кнопку «Generate speech», дождаться новых записей в `__caps`, отправить байты `fetch('http://127.0.0.1:7777/save?name=<id>_a.mp3', {method: 'POST', body})`.
4. Голос выбирается в правой панели: поиск по имени → кнопка `Select <имя>` → проверить по тексту страницы, что выбран нужный (интерфейс обновляется с задержкой).
5. Вызов JS обрывается через ~45 с, поэтому длинную очередь запускай без await (`window.__job = (async () => {...})()`) и проверяй `window.__log`.
6. Токены авторизации и cookies не трогать. Байты брать только из перехваченных ответов: `<audio>` с blob не скачивается.
7. Кредиты закончились — сказать пользователю, он сменит аккаунт.

Голос рассказчика выбирай быстрый и живой. Персонажам — разные голоса, чтобы различать на слух.

## Проверка озвучки
Claude не слышит звук. Строки `CHECK` из `prep-timeline` ловят обрезанные и зашумлённые реплики по длине, но интонацию и акцент не поймают. Поэтому после озвучки попроси пользователя послушать 2–3 реплики (файлы в `public/vo/`) или в конце честно скажи, что голос на слух не проверен.
- Файлов столько же, сколько реплик (кроме `reuse`): `node -e` сравнить `lines.json` и `public/vo`.
- Ни одна не обрезана, нет чужих голосов: прослушай подозрительные. Короткая реплика длиннее 6 с — значит, захватилось лишнее.
- `node tools/prep-timeline.mjs` сам отрезает тишину и вздохи в начале и конце и строит `timeline.json`.
