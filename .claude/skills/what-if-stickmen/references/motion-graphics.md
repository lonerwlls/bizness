# Моушн-графика

Правило: графика всегда анимирована — появляется с характером, живёт (дрейф, пульс, качание) и уходит. Текст, который просто появился и висит, — брак.

## Готовые компоненты
| Компонент | Где | Что делает |
|---|---|---|
| `HeroBadge` | kit | Табличка-счётчик над героем: прокрутка цифр, «поп», кольцо, искры и всплывающее «+N / −N» при каждом изменении (значения — `STORY.counter.keys`) |
| `AgeBadge` | ui | Та же табличка без логики (подпись и число задаёшь сам) |
| `NeonCounter` | graphics | Табличка «включается» как неон (мерцание), цифры набегают от→до, затем поп с кольцом |
| `Callout` | graphics | Выноска: точка с кольцом на детали, линия рисуется к плашке с текстом («ЩЕТИНА»). В шортсе `align="center"`, чтобы плашка не вылезала из узкого окна |
| `IdCard` | graphics | Паспорт/документ: въезжает с поворотом, поля проявляются, число набегает, штамп падает с тряской |
| `Split` | graphics | Сравнение двух состояний: половины въезжают с разных сторон (`vertical` — сверху/снизу для 9:16). Вместо человечка можно своя картинка (`icon`), длинная надпись сама уменьшается |
| `Bubble` | ui | Речь/мысль: упругий поп, покачивание, тень, контур. Внутри — иконка/цифра/рисунок, не длинный текст |
| `Accent` | ui | Плашка-акцент: слова влетают по одному, цветная полоса проезжает снизу |
| `RuleCard` | ui | Доска «ПРАВИЛО N»: выезжает, текст пишется мелом слева направо с пылью, можно зачеркнуть (`strike`) и дописать (`fix`) |
| `PhoneChat` | ui | Чат в телефоне: сообщения пружиной, плавная прокрутка, «печатает…» перед чужим сообщением, счётчик прочтений |
| `Board` | ui | Фон для инфографики (сетка, градиент), сам поворачивается в 3D на смене ракурса. `vertical` — 1080×1920 для вертикальных карточек шортса |
| `Cite` | ui | Источник факта в углу (имя, год). На вертикальной карточке задай `x`/`y` (например, 1040, 1880) |
| `Caption` | graphics | Крупный заголовок/призыв (хук в начале шортса, финальный вопрос) |
| `Pop`, `flash` | kit | Пружинное появление чего угодно; белая вспышка |

## Как придумывать графику
- Число в сюжете → табличка или набегающий счётчик, а не просто текст.
- Сравнение «было/стало», «по паспорту/в зеркале» → `Split`.
- Деталь на персонаже (щетина, синяк, значок) → `Callout`.
- Факт со статистикой → `Board` с точками/столбиками, которые вырастают по одному под слова, и `Cite`.
- Правило мира → `RuleCard` (один раз объявили — потом можно зачеркнуть и исправить).
- Переписка → `PhoneChat`; документ → `IdCard`.
- В шортсе всё крупнее: текст от 60 px, одна мысль на экран.

## Синхрон
Каждое появление привязывай к слову: `at('012') + N` кадров. Паузы и начала слов видны в `src/story/timeline.json` (`env` — громкость по кадрам). Щелчки, «+1», штампы — ровно на слово, которое их вызывает, а не «где-то в сцене».
