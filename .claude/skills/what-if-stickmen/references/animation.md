# Анимация: риг стикмена, библиотека действий, локации

Всё в шаблоне проекта (`src/`). Эталоны постановки — `references/examples/opening.tsx` (паспорт → зеркало → щетина → табличка → сплит) и `gosha.tsx` (встреча, рукопожатие, жесты под слова, касание щетины пальцем). Они написаны под старый проект («Ложь»), поэтому импорты в них другие. Копируй приёмы, а не файлы.

## Как устроена сцена (shot)
```tsx
const S3: React.FC = () => {
	const {f, gf, at, end, dur} = useShot();   // f — кадр внутри сцены, gf — кадр всего ролика, at('012') — где начинается реплика 012
	const sp = useSpeaking(gf);                 // кто говорит сейчас (камера на нём, без мигания в паузах)
	const cam = usePush(camOn(960, 560, 1.0), camOn(900, 520, 1.15));  // наезд за сцену
	return (
		<Stage cam={cam} bg="#f1e6c8" light={{x: 20, y: 10, o: 0.42}}>
			<Layer depth={1.6}><Corridor f={gf} /></Layer>            {/* фон: дальше, мягко размыт */}
			<Layer depth={1}><Svg>{/* персонажи и всё важное */}</Svg></Layer>
			<Layer depth={0.6}><Svg>{/* передний план: пролетает размытым */}</Svg></Layer>
		</Stage>
	);
};
```
- `camOn(X, Y, zoom)` — кадрировать точку мира (X, Y) с увеличением zoom (1 — весь кадр, 1.7 — крупный, 2.3 — очень крупно лицо). Центр головы стоящего персонажа масштаба s на полу 900: Y = 900 − 157·s − 164·s. При s = 1 это ≈ 580, макушка ≈ 530, табличка над головой ≈ 465.
- `mixCam(a, b, k)`, `usePush(a, b)` — переходы камеры. Авторакурсы (смена плана каждые 3–8 с) Stage добавляет сам.
- Мир — 1920×1080, пол обычно y = 900. Сидящий: `seat={790}` и `<Chair x y={800}/>`.
- Всё, что привязано к миру (луч фонарика, «ПУФ!», выноска на предмете, небо с луной), рисуй внутри `<Layer depth={…}><Svg>` — тогда оно едет вместе с камерой. `<AbsoluteFill>` поверх Stage — только для экранных надписей, которые не должны двигаться с миром (заголовок, призыв).

## Персонаж: `<Actor/>`
```tsx
<Actor who="hero" x={w.x} floor={900} s={1.05} facing={1} faceTurn={0.6} look={[0.8, 0]}
       expr="worried" mouth="open" pose={pose} vx={w.vx} bob={w.bob} armOver handF="point" uid="h1" />
```
- `who` — id из `story/cast.ts`. Рот шевелится сам по громкости его реплик, моргание само, у героя табличка и «старение» — от счётчика.
- `expr`: normal | angry | sad | sleepy | wide | worried. `mouth`: line | frown | open | smile | flat | smirk | none. `look` — куда смотрят зрачки [-1..1, -1..1]. `faceTurn` — поворот лица к собеседнику (0–0.6). `facing` — 1 вправо, −1 влево.
- `armOver` — передняя рука рисуется поверх лица (ладонь у щеки, фейспалм, палец у губ). `handF="point"` — указательный палец, `"snap"` — щелчок, `"fist"`.
- `vx` — скорость (пикс/кадр): размытие в движении. `bob` — подпрыгивание шага. Оба отдаёт `walkTo`.
- Тень под ногами рисуется сама (`shadow={false}` — убрать, например в отражении).
- Также есть: `hood` (капюшон), `lidL/lidR` (подмигнуть — прикрыть одно веко), `squash` (сплющивание при ударе/прыжке), `age` (0..1 — щетина, морщины, мешки), `acc` (headphones, mustache, glasses), `chestText` (бейдж на груди).

## Позы и действия (`kit/actions.tsx`)
Поза — данные `{lean, head, armB, armF, legB, legF}`, углы в градусах. Всё — функции «поза → поза», их можно вкладывать друг в друга.
- `idle(f, seed)` — дыхание, покачивание. `walk(ph)`, `run(ph)`, `SIT`.
- `env(f, t0, t1, in, out)` — 0→1→0 по времени. Это главный инструмент: каждый жест живёт от слова до слова.
- `blend(a, b, k)` — плавно перейти от позы a к позе b.
- `walkTo(f, t0, t1, x0, x1, seed, speed)` → `{x, pose, facing, vx, bob, moving}`. Вход с края кадра: x0 = −250 или 2200.
- `gesture(name, base, k, f)`: `touchFace`, `rubChin`, `facepalm`, `scratch`, `shrug`, `point`, `presentF`, `stop`, `handsOnHead`, `wave`, `armsCrossed`, `think`, `fist`.
- `reach(pose, 'F'|'B', [x, y], k)` — обратная кинематика руки: кисть в точку. Точка в локальных координатах тела (бедро = 0,0; x — вперёд по взгляду; голова около [0, −164], грудь [15, −95], подбородок [20, −120]). Мировую точку переводит `toLocal(wx, wy, x, y, scale, facing)` из `engine/Stickman`.
- `handshake(pA, pB, k, f, A, B)` — двое тянут руки навстречу и трясут (так же делается «дай пять»).

Пример: друг подходит и трогает щетину героя пальцем.
```tsx
const w = walkTo(f, at('025') + 6, at('025') + 34, 1150, 905, 7, 0.3);
const chin: [number, number] = [770 + 22 * sL, headY + 42 * sL];
const touch = env(f, at('025') + 36, at('025') + 128, 10, 10);
const gp = reach(w.pose, 'F', toLocal(chin[0], chin[1], w.x, 900 - 157, 1, -1), touch);
```

## Толпа, отражения, сон
- `CrowdRow` (mode: dance | stand | run | walk | panic), `Extra` — один статист.
- `Mirror` — отражение: рисуй внутри персонажа повёрнутым к камере (`facing={-1}`, `faceTurn≈0.1`), слой глубины 1 — иначе размоет.
- `Sleeper` — лежит в кровати (`Bedroom`, `Blanket`).

## Локации (`kit/sets.tsx`) и пропсы
- Квартира: `Bedroom` (день/ночь, будильник), `Blanket`, `Kitchen` (день/ночь), `KitchenTable`, `Win` (окно с небом), `Lamp`.
- Город: `Elevator`, `Pharmacy` + `Counter`, `Shop`, `Entrance` (вход с охраной), `NightStreet` (пожарная машина).
- Школа: `SchoolYard`, `Corridor` (шкафчики, радио), `ClassroomEve`, `Toilet` (зеркало), `HallBack` (актовый зал: сцена, занавес, гирлянды, дым, диско-лучи).
- Из эталонных сцен (`reference/PauseTime.tsx`, `Highway.tsx`): `Sky`, `Skyline`, `Facades`, `Street` (мокрая дорога), `LampPost`, `Shelter` (остановка), `Rain`, `Car`, `Splash`, `Neon`, `Onoma` (звукоподражание «ХЛОП!»), `Bokeh`, `HighwaySky`, `HighwayMesas`, `HighwayGround` (шоссе в пустыне), `HighwaySparks`.
- `engine/props.tsx`: `Desk`, `Chair`, `Bottle`, `Badge`.
- Нужна локация, которой нет, — нарисуй её в `src/story/places.tsx`: локации этого ролика живут рядом с его сценами, общий `kit/sets.tsx` не трогаем. Образец — любая локация из `kit/sets.tsx` или `Street`/`Shelter` из `reference/PauseTime.tsx`: небо или стена градиентом, пол или земля, 2–3 крупных предмета, один источник света, параметр `night`. Без мелкой детализации, стиль плоский и крупный, но не беднее `Reference`: добавь глубину (дальний слой силуэтов), свет и одну живую деталь (мерцание, волны, листва).

## Подводные камни
- Хуки (`usePush` и другие `use…`) вызывай всегда, а не внутри `if`.
- Не передавай `pose={undefined}` с намерением «по умолчанию» — Actor сам подставит idle, если pose не задан.
- Масштаб: герой не должен быть огромным рядом с машиной или остановкой. Ориентир — `Reference`: персонаж ≈ 0,95, машина ≈ 1.
