# Рендер и проверки

## Команды (из папки проекта)
| Команда | Что делает |
|---|---|
| `node tools/check-plans.mjs` | До рендера: длина каждого плана (> 10 с — ошибка), пишет `auto-cues.json` для звука |
| `node tools/storyboard.mjs Long` | Раскадровка: кадр из середины каждой сцены одним листом → `out/storyboard_Long.jpg` |
| `node tools/storyboard.mjs Short --every 2.5` | Лист кадров каждые 2,5 с (проверка монтажа) |
| `node tools/storyboard.mjs Long --frames 120,121,122` | Конкретные кадры (подозрение на мигание) |
| `npx remotion still Long out/f.jpg --frame=300 --gl=angle` | Один кадр в полном размере |
| `node tools/render.mjs Long --estimate` | Оценка времени рендера |
| `node tools/render.mjs Long` | Полный рендер кусками → `out/Long.mp4` |
| `node tools/render.mjs Short` | То же для шортса + `out/Short_phone.mp4` (лёгкая копия для телефона) |
| `node tools/check-video.mjs out/Long.mp4` | Проверка готового файла |
| `npx remotion studio` | Интерактивный просмотр в браузере (пользователю, если хочет сам листать) |

## Как устроен рендер
- **Ускорение видеокартой** (`--gl=angle`) включено везде. Без него размытые слои рендерятся в 20–30 раз медленнее: 300 кадров идут полчаса вместо минуты.
- **Картинка рендерится без звука кусками:** лонг по 2500 кадров (≈83 с), шортс по 600 (20 с). Сбой теряет один кусок, а не всё. Упавший кусок скрипт сам повторяет до 3 раз, каждый раз с меньшим числом вкладок браузера. Повторный запуск пропускает готовые куски. Правка в одной сцене — удали только кусок, где она (`out/chunks_Long/cNN.mp4`), и запусти снова. Число параллельных вкладок — `"concurrency"` в `src/story/render.json` (по умолчанию 6, на слабом компьютере 2–4). `--chunk N` — свой размер куска.
- **Звук** собирается не проходом Remotion (он прогоняет все кадры и идёт около часа), а напрямую из тайминга (`mix-audio`, секунды) и выравнивается до −16 LUFS. Видео при этом не перекодируется.
- **Время.** Лонг 13 минут — около 30 минут на обычной видеокарте, шортс 60 с — 2–4 минуты. Перед рендером оцени время (`--estimate`) и скажи пользователю. Дольше 20 минут — запускай в фоне и сообщай прогресс по кускам.

## Проверка готового файла (`check-video.mjs`)
- Длительность и размер правильные, звук есть.
- **Мигания** — одиночные кадры другого плана (1–3 кадра между двумя склейками). Список времён: открой эти кадры (`storyboard --frames`) и пойми, баг это или задуманный эффект. Норма: затемнение в начале, белая вспышка, тряска, вжух, въезд половинок сплита. Баг: кадр другого плана или сцены посреди диалога, кадр общего плана между двумя крупными.
- Большая разница на стыке кусков, если стык попал на вжух или склейку, — тоже норма.
- **Чёрные кадры** — не должно быть, кроме первых и последних 10 кадров.
- **Статичные участки** — больше 2 с без движения. Не должно быть.
- **Стыки кусков** — разница на границе куска. Маленькая = чисто. Большая — открой кадры до и после.
- **Громкость** — −16 LUFS, пик ≤ −1 dB.
