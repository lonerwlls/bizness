# «The Ladder» — притча в стиле NEURONVISUALS (Higgsedit, объёмная сцена)

Готовое видео: `videos/the-ladder.mp4` (1080×1920, 30 с, 30 fps, только звуки, −14 LUFS).

- `edit/` — проект Higgsedit: `scene.glsl` + `lib.glsl` — объёмная сцена (стена-плато, лестница, стол, лампа, стулья),
  `world.js` — размеры мира, `camera.js` — планы камеры и плавные переходы, `people.js` — скелеты человечков,
  `draw.jsx` — проекция и плоские силуэты, `timing.js` — все тайминги, `edit.jsx` — сборка.
  Рядом нужен шрифт `Tektur.ttf` (Google Fonts, OFL).
- `sfx/` — синтез звуков кодом (`events.mjs` собирает события, `sfx_ladder.py` синтезирует).

Звуки синтезированы кодом, права на них принадлежат автору канала.
