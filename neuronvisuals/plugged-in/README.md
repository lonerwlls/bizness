# «Plugged In» — подписки: неоновый герой, провода из иконок, отъезд в телефон, петля

Готовое видео: `videos/plugged-in.mp4` (1080×1920, 30 с, бесшовная петля, только звуки, −14 LUFS).

- Мир (`scene.glsl`): лежащий телефон, экран — пол, иконки приложений; подключённые иконки светятся оранжевым.
- Герой (`people.js`, `neon.jsx`): сидит в кресле, каждая подписка тускнит неон; под свечением — тёмная «стеклянная» трубка, видна, когда он гаснет.
- Провода (`cables.jsx`): дуга из иконки к суставу, по проводу от героя к иконке бегут знаки «$», ценники. Подписок 6.
- Счётчик MONTHLY/YEARLY; факт крупно в две строки: YOU THINK $86/MONTH, REALITY $219/MONTH (опрос C+R Research, 1000 американцев).
- Звук (`sfx/`): синтез кодом, три ноты на повороте, блокировка/разблокировка экрана.
