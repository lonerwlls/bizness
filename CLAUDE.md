# Финансовые шортсы (Remotion)

Пользователь пишет с телефона, компьютера у него нет, в программировании он новичок. Отвечай по-русски, коротко и без жаргона. Всё делай сам, а пользователю давай только результат и простые вопросы.

## Что тут есть
- Вертикальные шортсы 1080×1920 в духе «как гиганты на самом деле зарабатывают». Длина 45–70 сек. Озвучка, смена картинки на каждом ключевом слове, звуки, музыка, маскот Уильям Денежкин (`src/finance/Gent.tsx`).
- Два стиля:
  - `src/finance/engine.tsx` — `FinanceShort`: эмодзи и крупный текст. Темы в `src/finance/topics/index.ts`, пример: `ikea`.
  - `src/finance/editorial.tsx` — `EditorialShort`: журнальный стиль с рубрикой, заголовком и субтитрами. Темы в `src/finance/topics/editorial.ts`, пример: `apple`.
- Каждая тема — композиция `Fin-<id>`.

## Стиль «анимационная история» (новый, основной для сюжетных роликов)
**Правила пользователя (всегда):**
- Главный герой во всём ролике — один и тот же `MASCOT`. Никогда не подменяй его другим персонажем в других сценах: даже если сюжет про реального человека, этого человека играет MASCOT.
- Надписи поверх кадра: в «Last man on Earth» (с части 2) — как в примере пользователя: счётчик дней сверху, плашки над сценами, карточки глав и крупные субтитры по 2–4 слова, всё на английском. В остальных роликах — уточняй у пользователя (раньше он просил без надписей).
- Озвучку не вшиваем: отдаём пользователю текст по секундам (фразы по 6–7 сек), субтитры совпадают с этим текстом.
- Ролики — на английском: озвучка, тексты в кадре (вывески, газеты) и всё, что видит зритель. С пользователем общаемся по-русски.

- Персонажи — плоские «куклы» в `src/characters/Rig.tsx`: `<Person x y s pose look face feet hands pole .../>`.
  Главный герой канала — `MASCOT` (оранжевая куртка, тёмная шапка с помпоном). Его используем во всех следующих роликах.
  Остальные (`PETIT`, `FRIEND1/2`, `COP`, `PASSER[]`) — тот же риг, другая внешность. Новых людей делай так же, через `Look`.
- Двигается всё: `feet`/`hands` — точки, к которым тянутся ступни/кисти (колени и локти считаются сами), `walkRig` в `src/towers/towers.tsx` — шаг по любой поверхности, `face` — глаза/брови/рот, моргание и дыхание автоматически (`t` = кадр).
- Лист персонажей для проверки: `npx remotion still src/towers/index.ts Char-sheet out/sheet.png`.
- Пример ролика: `src/towers/towers.tsx` (композиция `Fin-towers`). Тёмно-синий фон, плоские фигуры, звук — `scripts/towers_sound.py`.
- Шрифты для рендера лежат локально (`public/towers/fonts`), потому что браузер рендера в облаке не скачивает Google Fonts.

## Подготовка (один раз за сессию)
```bash
npm install
command -v ffmpeg || (sudo apt-get update && sudo apt-get install -y ffmpeg) || true
```
Если ffmpeg поставить не получилось, `scripts/make.sh` сам возьмёт `npx remotion ffmpeg`. Тогда в скриптах озвучки замени `ffprobe` на `npx remotion ffprobe`.
Для рендера Remotion при первом запуске скачивает Chrome, поэтому в настройках облачного окружения нужен доступ в интернет.

## Как сделать новый ролик
1. **Сценарий.** Напиши `public/finance/<id>/script.txt` на 130–170 слов. Первая фраза — крючок-вопрос. Числа пиши словами («девяносто пять процентов»). На названиях брендов ставь ударение символом U+0301. В конце — призыв подписаться. Факты проверяй и не выдумывай.
2. **Озвучка** (одним куском, чтобы интонация была цельной):
   - Бесплатно, Edge TTS: `node scripts/tts_edge.mjs public/finance/<id> src/finance/topics/<id>.voice.ts public/finance/<id>/script.txt ru-RU-DmitryNeural +10%`. Голос с акцентом: `en-US-AndrewMultilingualNeural +15%`.
   - ElevenLabs, звучит живее: нужна переменная окружения `ELEVENLABS_API_KEY`. Команда: `EL_MODEL=eleven_v3 node scripts/tts_eleven.mjs full public/finance/<id> src/finance/topics/<id>.voice.ts public/finance/<id>/script.txt pNInz6obpgDQGcFmaJgB` (голос Adam).
3. **Биты.** Добавь объект темы в массив (в стиле примера). Бит `{ at: "слово", n?: номер_повтора, k: шаблон, ... }` срабатывает на слове из озвучки. Шаблоны и их поля описаны в типе `Spec` в `engine.tsx`. Картинка должна меняться каждые 1,5–2 сек: медленные ролики не смотрят. Нужные эмодзи бери из `src/finance/fluent.ts`. Фото кладутся в `public/finance/photos/<name>.jpg` (поле `photo`).
4. **Проверка:** `npx tsc`. Затем `npx remotion still Fin-<id> out/check.png --frame=<N>` на 3–4 кадрах. Посмотри картинки сам: текст не должен вылезать за край, ничего не должно перекрываться.
5. **Рендер:** `bash scripts/make.sh <id>`. Получится `videos/<id>.mp4`, громкость выровнена.
6. **Отдать пользователю:** сделай коммит `videos/<id>.mp4` и исходников и push. Скажи ему, что видео лежит в репозитории в папке `videos`: открыть файл → «⋯» → Download. Файл должен весить меньше 100 МБ. Если больше, подними `-crf` в `make.sh`.

## Музыка и реклама
- `public/finance/music.mp3` — простой бит-заглушка. Пользователь может заменить его своим треком с тем же именем. Для темы можно указать свой трек полем `music: "finance/<файл>"`.
- В середине ролика можно оставить паузу под рекламу. Для этого в `engine.tsx` поставь `AD_FRAMES = Math.round((7.2 / 1.3) * FPS)` и положи рекламное видео с зелёным фоном в `ads/ad.mp4`. Остальное `make.sh` сделает сам. По умолчанию рекламы нет.

## Экономия
- Большие файлы (`engine.tsx`, `editorial.tsx`) не читай целиком: ищи нужное через grep.
- Рендер долгий, запускай его один раз, когда всё проверено на стоп-кадрах.
